# 手动配置启动器的认证服务器

启动器需要配置GTMC的认证服务器并登入账号才能正常进入我们的服务器

**你需要准备：** 

1. [GTMC 皮肤站](https://skin.gtmc.top)账号
> 没有这个？请阅读 [加入服务器](joining.md) 第一、二步
2. 一个支持 **第三方登录** 的启动器。例如 *PCL2(Windows)* 或者 *Axolotl(MacOS)*
3. 复制这个认证服务器地址： `https://skin.gtmc.top/api/yggdrasil`

根据你的启动器选择教程：

## HMCL
点击左上角 「账户」，点左下角 「添加认证服务器」，输入上方认证服务器地址

## PCL2
「启动游戏」 ⟶ 下方 「版本设置」 ⟶ 左侧 「设置」 ⟶ 页面下方 「服务器选项」，输入上方认证服务器地址

## Axolotl Launcher
任意页面右侧中间小箭头「展开边栏」 ⟶ 「添加第三方账号」 ⟶ Yggdrasil API 地址输入认证服务器地址，账号密码输入你的GTMC账号密码 ⟶ 「登录」
