## 服务器规则摘要

- 不允许使用任何修改行为的客户端模组（透视、自动挖掘、飞行等）。
  **小地图、显示优化、光影属于允许范围**。
- 不允许利用复制、区块加载漏洞等原版 bug 获利。
- 破坏他人建筑、偷窃、恶意 PvP 一律按 [社群规范](/community/) 处理。
- 大型红石机器上线前请先在频道里报备，避免卡服。

## 卡顿排查

如果服务器卡顿，先按顺序自查：

1. 是不是自己周围有大量实体（掉落物、矿车、生物）？
2. 是不是新上线了高频红石机器或漏斗阵列？
3. 在频道里报一下 **坐标 + 大概时间**，方便管理员看日志。
