# 服务器一览

社团的服务器都是 **Minecraft Java 版**，用社团的皮肤站登录：只有用校园邮箱注册、在皮肤站建了角色的人才进得去，
别人冒用你的名字也进不来。第一次进服请看 [加入服务器](/server/joining)。

::: tip 地址和在线人数以论坛为准
服务器的连接地址偶尔会变，所以不写在 Wiki 里。打开 [论坛](https://forum.gtmc.top) 首页，
右栏的「服务器」面板列出了每个服的地址（点复制按钮即可）、版本和当前在线的人。手机上在首页顶部。
:::

## 通用规则

服务器里同样适用 [社群规范](/community/)，另外：

- **一个人一个角色。** 角色名就是你的游戏名，存档、背包、领地都跟着它走，别换名字重进。
- **被封了走申诉，不要换号。** 封禁在皮肤站做，换号只会让处理时间变长。
- **大型机器先打招呼。** 高频红石、大规模漏斗阵列、刷怪塔上线前，在论坛或群里说一声，免得卡服。
- **别人的建筑不要动。** 想改、想拆、想借用，先问建造者。

## 服务器卡了

先自查，再上报：

1. 自己附近是不是有大量实体（掉落物、矿车、生物）？
2. 最近有没有新上线的高频红石机器？
3. 都不是的话，在论坛「白名单与申诉」或群里报一下 **哪个服 + 坐标 + 大概时间**，方便管理员查日志。
