# 加入方式

::: warning 占位内容
申请表单链接与审批人尚未填写，请管理员补充。
:::

## 前置条件

1. 拥有一份 **正版 Minecraft Java Edition** 账号。
2. 是 GTIIT 在读学生、教师或社团认可的成员。
3. 同意 [社群规范](/community/)。

## 申请流程

1. 在社团 Discord / QQ 群中找到当周的 **白名单申请** 帖子。
2. 填写以下信息（不要公开提交你的密码或邮箱密码）：

   ```text
   Minecraft ID：
   常用称呼：
   意向玩法（生存 / 建筑 / 红石 / 活动）：
   是否已阅读社群规范：是
   ```

3. 管理员审核后会将你加入白名单，通常在 **48 小时内** 完成。
4. 收到通过通知后，按服务器地址连接即可。

## 首次进入要做什么

- 先读 `/rules` 与 `/help`。
- 在出生点附近领取新手装备箱。
- 选定据点前，用 `/map` 看看已有建筑，避免盖在别人规划区里。
- 远处建家记得随手放 `/sethome`。

::: tip 卡在登录界面？
常见原因是版本不符或未加白名单。先核对版本号，再在频道里 @ 管理员确认白名单状态。
:::
