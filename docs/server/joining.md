# 加入服务器

社团服务器不用正版账号，用的是社团自己的 **皮肤站** 登录。整个流程大约十分钟。

**你需要：** 一个 `@gtiit.edu.cn` 校园邮箱，一个支持「外置登录（authlib-injector）」的启动器。

## 第一步：注册 GTMC 账号

1. 打开 [auth.gtmc.top](https://auth.gtmc.top)，点「注册」。
2. 邮箱只能填 `@gtiit.edu.cn` 校园邮箱，其他邮箱会被拒绝。
3. 去邮箱点验证链接（可能在垃圾箱里）。

这个账号同时用于论坛、皮肤站和 Wiki，只需要记一个密码。

## 第二步：在皮肤站建角色

1. 打开 [skin.gtmc.top](https://skin.gtmc.top)，用 GTMC 账号登录。
2. 进「角色管理」，新建一个角色。角色名就是你在服务器里的游戏名。
3. 想要皮肤的话，在「皮肤库」上传或挑一个，然后应用到角色上。

::: warning 老玩家注意：名字要一模一样
以前在服务器玩过的话，新建角色时**名字要和原来的游戏名完全一致，大小写也一样**，
原来的存档、背包和进度才接得上。名字打错了只能重新建角色，旧存档不会跟过来。
:::

## 第三步：启动器添加外置登录

在启动器里添加一个「外置登录」或「authlib-injector」账户，服务器地址填：

```text
https://skin.gtmc.top/api/yggdrasil
```

账号和密码就是 GTMC 账号的**邮箱**和**密码**。登录后选择你在第二步建的角色。

常见启动器都支持外置登录，名称略有不同：

| 启动器 | 在哪里添加 |
| --- | --- |
| HMCL | 账户 → 添加账户 → 外置登录（authlib-injector） |
| PCL | 启动 → 登录方式选「第三方登录（Authlib Injector）」 |
| Prism Launcher | 账户 → 添加 authlib-injector |

::: tip 地址可以直接拖
部分启动器支持把皮肤站页面上的 authlib-injector 地址直接拖进账户窗口，效果和手动填一样。
:::

## 第四步：申请白名单

1. 登录 [论坛](https://forum.gtmc.top)，进「白名单与申诉」版块，点「新建话题」。
2. 标题写 `【申请】你的游戏名`，正文里已经预填了一行，补上游戏名（区分大小写）就行。
3. 一般 24 小时内有人处理。着急就在社团群里 @ 管理员，不要重复发帖。

## 第五步：进服

在论坛首页右栏的「服务器」面板里复制想去的服的地址，
在游戏里「多人游戏 → 添加服务器」填进去，用第三步的外置登录账户启动游戏即可。

## 进不去？

**提示「无效的会话」或「未通过验证」。**
启动游戏用的不是外置登录账户，或者登录过期了。回启动器重新登录外置账户再试。

**皮肤没显示。**
确认皮肤已经应用到你用的那个角色上。改完皮肤后重进服务器才会刷新。

**注册时提示邮箱不被允许。**
只接受 `@gtiit.edu.cn`。用的确实是校园邮箱仍被拒，到论坛「新人指南」版块发帖，或在群里找管理员。

**以前的存档不见了。**
多半是角色名和原来的游戏名大小写不一致。到「白名单与申诉」发帖说明原来的名字，管理员帮你看。
