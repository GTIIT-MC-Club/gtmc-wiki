# 社群规范

这些规则不多，都跟「让下一个人看得懂」有关。论坛、服务器、社团群都适用。

## 几条规则

1. **一个话题一件事。** 标题写清楚是什么事，别用「问一下」「求助」这种标题。
   同时问三件事，就发三个话题，方便别人回答，也方便后来的人搜索。
2. **发帖前先搜一下。** 服务器地址、白名单流程、装模组出问题，多半已经有人问过，或者已经写进了 Wiki。
3. **不吵架，不人身攻击。** 对事不对人。有分歧就说你的判断和依据，不必说服对方。
4. **不泄露别人的信息。** 学号、手机号、宿舍号、成绩，未经本人同意不要发。
   发截图前把聊天记录里的名字和信息涂掉。
5. **服务器里的事，在论坛里说清楚。** 被封了要申诉，写清楚发生了什么，
   不要换个游戏名重新进服，那样只会让处理时间变长。
6. **不发广告。** 与 Minecraft、社团、学校无关的推广会被删除。
7. **密码不外借。** 账号就是你，借出去之后做的事都算你的。

## 服务器里

- 不用透视、自动挖掘、飞行、杀戮光环这类改变游戏行为的作弊客户端或模组。
  小地图、性能优化、光影、材质包没问题；拿不准就先在论坛「技术开发」问一句。
- 不利用复制物品之类的漏洞获利。发现了漏洞，私信告诉管理员。
- 不破坏、不偷拿别人的东西，不恶意 PvP。

## 违规怎么处理

管理员处理违规的顺序一般是：

1. 删帖（或回滚破坏）并说明原因
2. 私信提醒
3. 短期禁言或封禁
4. 封号

严重的情况（冒用他人身份、大规模破坏、泄露隐私）可能直接封号。犯错了好好说一句就行，不用怕。

觉得处理有误，到论坛「白名单与申诉」版块发帖，标题写 `【申诉】你的游戏名`，写清楚经过。

## 有事找谁

| 情况 | 去哪 |
| --- | --- |
| 论坛功能出问题、帖子发错版块 | 在任何帖子下 @ 管理员，或到「白名单与申诉」发帖 |
| 服务器进不去、被封、怀疑有人冒名 | 论坛「白名单与申诉」，写清游戏名和经过 |
| 涉及隐私、不想公开 | 给管理员发论坛私信 |
| Wiki 写错了 | 直接 [改](/guide/contributing)，或在论坛说一声 |
