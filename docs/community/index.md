# 规范与准则

::: warning 占位内容
处置流程与申诉渠道需由社团管理层确认后替换。
:::

GTMC 的目标是让每个人都能安心地把时间花在建造和探索上。
以下约定适用于服务器、语音频道与群聊。

## 一、尊重他人

- 不使用侮辱、歧视、骚扰性语言。
- 未经允许不公开他人现实身份、联系方式与住址。
- 频道里出现争执时，就事论事，不翻旧账。

## 二、尊重他人的劳动

- 不破坏、不挪用、不"顺手"拿走别人箱子里的东西。
- 想使用他人建筑（如公共农场）请先询问，并遵守其补充说明。
- 发现疑似破坏，截图 + 坐标发到管理频道，不要自行"报复性"破坏。

## 三、公平游戏

- 禁止外挂与自动脚本。
- 禁止复制、刷物品、刷经验类原版漏洞。
- 禁止利用管理员身份为自己或朋友谋利。

## 四、技术自保

- 不上传、不传播含密钥或私人信息的文件。
- 不点击陌生链接，尤其是"免费皮肤 / 存档下载"类。

## 处置方式

| 情节 | 处理 |
| --- | --- |
| 首次轻微违规（刷屏、破坏小范围植被） | 口头提醒 + 恢复原状 |
| 反复违规或破坏他人建筑 | 短期封禁，需说明情况后解封 |
| 外挂、复制、恶意破坏 | 永久封禁，社团内部公示 |

对处理结果有异议，可以在提交后 **7 天内** 向社长提出复核。
