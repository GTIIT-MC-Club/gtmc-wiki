# 社团简介

**GTMC** 是广东以色列理工学院（GTIIT）的 Minecraft 社团。我们一起建造、一起折腾红石、一起办活动，
社团自己运营几台 Minecraft Java 版服务器，在读的同学和老师都可以加入。

## 社团的几个网站

所有网站共用一个 **GTMC 账号**，只能用 `@gtiit.edu.cn` 校园邮箱注册。

| 网站 | 地址 | 用来做什么 |
| --- | --- | --- |
| 统一账号 | [auth.gtmc.top](https://auth.gtmc.top) | 注册、登录、找回密码。其他网站都跳到这里登录 |
| 论坛 | [forum.gtmc.top](https://forum.gtmc.top) | 公告、举报与申诉、晒建筑、技术讨论、活动报名；服务器实时状态 |
| 皮肤站 | [skin.gtmc.top](https://skin.gtmc.top) | 创建游戏角色、配置皮肤 |
| Wiki | 就是这里[wiki.gtmc.top](https://wiki.gtmc.top) | 长期有效的说明和教程 |

::: tip 论坛和 Wiki 怎么分工
论坛内容一般具有**时效性**：公告、讨论、某一次活动。Wiki 一般放**一直有效**的内容：进服步骤、服务器规则、技术教程。
在论坛里被反复问到的问题，将被适时整理进 Wiki。
:::

## 你想从哪开始？

1. **我想进服玩**：看 [加入服务器](/server/joining)。
2. **我想了解服务器**：看 [服务器一览](/server/)。
3. **我想发帖、参与讨论**：请先阅读 [社群规范](/community/)，再去 [论坛](https://forum.gtmc.top)。
4. **发现 Wiki 写错了或缺东西**：请阅读 [参与编辑](/guide/contributing)，人人都能改。

## 联系管理员

- 进不去服、被封、怀疑有人冒名：到论坛「举报与申诉」版块发帖，写清游戏名和经过。
- 涉及隐私、不想公开的事：在论坛给管理员发私信（信任等级 1 起可以发）。
- 着急的事：在社团群里 @ 管理员。
