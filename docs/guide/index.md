# 社团简介

**GTMC** 是广东以色列理工学院（GTIIT）的 Minecraft 社团。我们一起建造、一起折腾红石、一起办活动，
社团自己运营几台 Minecraft Java 版服务器，在读的同学和老师都可以加入。

## 社团的几个网站

所有网站共用一个 **GTMC 账号**，只能用 `@gtiit.edu.cn` 校园邮箱注册。

| 网站 | 地址 | 用来做什么 |
| --- | --- | --- |
| 统一账号 | [auth.gtmc.top](https://auth.gtmc.top) | 注册、登录、找回密码。其他网站都跳到这里登录 |
| 论坛 | [forum.gtmc.top](https://forum.gtmc.top) | 公告、白名单申请与申诉、晒建筑、技术讨论、活动报名；右栏能看到各服务器的地址和在线人数 |
| 皮肤站 | [skin.gtmc.top](https://skin.gtmc.top) | 建游戏角色、上传皮肤；服务器用它验证你的身份 |
| Wiki | 就是这里 | 长期有效的说明和教程 |

::: tip 论坛和 Wiki 怎么分工
论坛放**会过时**的东西：公告、讨论、某一次活动。Wiki 放**一直有效**的东西：进服步骤、服务器规则、技术教程。
在论坛里被反复问到的问题，就该整理进 Wiki。
:::

## 从哪开始

1. **想进服玩**：看 [加入服务器](/server/joining)。
2. **想了解服务器**：看 [服务器一览](/server/)。
3. **想发帖、参与讨论**：先读 [社群规范](/community/)，再去 [论坛](https://forum.gtmc.top)。
4. **发现 Wiki 写错了或缺东西**：看 [参与编辑](/guide/contributing)，人人都能改。

## 联系管理员

- 进不去服、被封、怀疑有人冒名：到论坛「白名单与申诉」版块发帖，写清游戏名和经过。
- 涉及隐私、不想公开的事：在论坛给管理员发私信（信任等级 1 起可以发）。
- 着急的事：在社团群里 @ 管理员。
